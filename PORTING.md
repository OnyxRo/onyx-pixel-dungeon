## Too Cruel PD Trials (2026-10-25, key `toocruel`)
Repo `~/mod-sources/toocruel` (Shattered 3.x base, almost all Kotlin), translated to Java by hand. Its challenge modifiers are game modes under Too Cruel Pixel Dungeon Trials in the Game modes window on hero select, ids `tc_<name>` from the mod's English names, text in `messages/misc/misc.properties` (rewritten to Onyx's writing rules).

How it is built.
- `TooCruel.java` (root package) registers the modes from `GameModes` (one line), keeps the mod's dependencies and its two conflicts (a one line call in `GameModes.set`), holds the trials and every hook. Shared Shattered files only gained one line calls marked `//toocruel` (Char, Hero, Mob, Level, RegularLevel, RegularPainter, Dungeon, Fire, Hunger, Regeneration, Potion, PotionOfShielding, Trap, Item, Challenges, TengusMask, WndChooseSubclass, GameScene, Wand, MissileWeapon, HeavyBoomerang, SpiritBow, Chasm, Bomb, SuperNovaTracker, ChampionEnemy, RatSkull, ExoticCrystals, StandardRoom, ConnectionRoom, MobSpawner).
- Crooked Die needs the engine's dice, so `com.watabou.utils.Random` gained a `crookedDie` flag with three checks. A helper class could not do it, `Random` lives in SPD-classes which cannot see core. `TooCruel.refresh` sets it at the start of a run and on load.
- Buffs are in `actors/buffs/toocruel/` (`TcBuff` holds the hook interfaces, `TcTrackers` the small buffs without text), the saint aura and the Postpaid Loot lock are blobs in `actors/blobs/toocruel/`, the IOU note is `items/toocruel/IOU`. The mimic family lives in the mobs package (`TcStoredHeapData`, `TcHolderMimic`, `TcHolderStatue`) so it can reach a statue's weapon and a mimic's prize.
- Floor changes run in `TooCruel.postCreate`, at the end of `Level.create` inside the floor's seeded generator, so they work on every world of the shuffle. They never call `Level.getTransition(int)` or `Dungeon.level`, which still point at the old floor while a new one is built.
- Trials. A Trials button at the top of the Too Cruel list opens `WndGameModes.WndTrials`, its 28 trials in Normal, Hard and Extreme, decoded once from the mod's Base58 strings into id lists in `TooCruel.TRIALS`. Picking one turns off the other Too Cruel modes, turns on the trial's modes and sets Shattered's challenges the trial names. The HTTP trial groups and score tables were skipped. A trial's locked hero is ignored.
